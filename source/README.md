# 原始碼專案

此目錄包含 Vite 原始碼。課程與分類資料位於 `src/course-data.js`，頁面渲染邏輯位於 `src/main.js`，樣式位於 `src/styles.css`。

## 本機預覽

```bash
npm install
npm run dev
```

## 建置 GitHub Pages 檔案

```bash
npm run build
```

將 `dist/` 中的所有檔案複製到 GitHub repository 根目錄。三個入口頁面分別是 `index.html`（課程總覽）、`abilities.html`（六大能力）與 `applications.html`（事業應用）。
